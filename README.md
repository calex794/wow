# wow — лаборатория формата Akula Network

Экспериментальный репозиторий для исследований двоичного формата сообщений между устройствами Akula.

- **Статус:** исследовательский стенд. Не использовать для реальных пользовательских данных.
- **Проект формата:** [AK-NET-WIRE-10 в Notion](https://app.notion.com/p/3fc32a84beec816ab4f1c6b5566efeb1).
- **Архитектура сети:** [AK-NET-ARCH-09 в Notion](https://app.notion.com/p/3fc32a84beec815ea6ffd8a68d78d8c2).
- **Основной продукт:** [Akula](https://github.com/Lalalalendia/Akula), его Sync Core и формат `WireEnvelope` здесь не изменяются.

Работу ведём в отдельных ветках с проверками. Сначала — строгая сериализация и разбиение сообщений по каналам, затем — подтверждения доставки и только после отдельной ревизии — настоящие подписи/шифрование.

> До внедрения проверенной криптографии и хранения ключей этот стенд **не** обеспечивает ни конфиденциальность, ни подлинность отправителя. Не подключать его к производственной сети или локальным файлам пользователя.

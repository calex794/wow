# Status / ограничения

Первая версия — **исследовательская**. Формат CBOR здесь временный, не совместим с проектным защищённым AkulaNetEnvelopeV0.

Реализовано:
- канонический узкий профиль CBOR с явными проверками длины;
- потоковое обрамление (4 байта длины);
- разбиение/сборка BLE-фрагментов и отбрасывание конфликтующих дубликатов;
- проверки на неверную версию, повреждённые значения и слишком длинные сообщения.

Пока **не реализованы**:
- COSE, HPKE, подпись, доверие к устройствам;
- доставка по настоящему BLE, iroh или Yggdrasil;
- квитанции, постоянный журнал, повторные попытки, защита от повтора между сеансами;
- проверка в живом окружении двух телефонов и сервера.

Не использовать на реальных данных. Эталон — [AK-NET-WIRE-10](https://app.notion.com/p/3fc32a84beec816ab4f1c6b5566efeb1).
